# boards/

Die eigenen Leiterplatten dieses Steuergeraets (`<board>/board.yaml`).

Der Assistent 'Neues Board' des Studios schreibt hierher. Ein Projekt nennt sein Board weiterhin ueber den Pfad, nicht ueber den Namen.

Gefunden wird der Ordner ueber `search.boards` in `nextbsw.yaml`; deshalb muss es ihn geben, auch wenn er noch leer ist. Diese Datei haelt ihn in git.
