# neXtBSW-Update 1.0.0 (23642a8d) -> 1.0.0 (a18a1e4d)

Entwicklungs-Pin auf Entwicklungs-Pin, beide ohne Release-Tag (`nextbsw.yaml`, customer-project.md 4.4).
Vorbereitet am 2026-11-06 im Zweig `pin-io125` auf Auftrag des Koordinators (IO-129 auf neXtBSW `dev` gemergt). Von Hand nach Abschnitt 5.5.

## Was neu ist, soweit es BattSimFW betrifft

- **IO-129** `FlexioI2cBuses::init` muxt SDA und SCL per `Io::setDefaultConfiguration` vor dem Start des Masters (Fix 2ce96932). Vorher blieben
  PORTE_PCR15/PCR16 auf 0, FlexIO sah die Pins nie high, jeder Auftrag endete mit `BUS_BUSY`; die Anzeige war mit 0.5.0, 0.5.1 und 0.5.2 dunkel
  (Befund am Geraet 06.11., `doc/geraetetermin-anzeige-2026-11-04.md`, Nachtrag). Der Pull-up aus IO-125 steht im selben PCR-Eintrag und wirkt jetzt erst.
  Neues Generat-Makro `NX_I2C_BUS_PINS` in `i2cConfiguration.h` (Bus-Index, SDA-Pin, SCL-Pin); Host-Test `flexio-i2c-pins` erwartet PCR15 0x0600, PCR16 0x0603 (SCL mit Pull-up).
- Sonst Motor-/Safety-/Test-/Studio-Themen der Eval-Board-Seite (u. a. `pin_test_off`, boardtest): wirken im BattSim-Abbild nicht.
- Das verschachtelte Untermodul `external/openbsw` bleibt auf 6e06d961 (2026.10) (`git submodule update --init external/openbsw` im nextbsw).
