# mcudb/

Eigene Derivatbeschreibungen dieses Repositorys (`<familie>/<derivat>.yaml`).

Nur noetig, wenn ein Derivat im gepinnten Release fehlt; sonst gehoert es nach oben in neXtBSW (Regel R11 der Architektur).

Gefunden wird der Ordner ueber `search.mcudb` in `nextbsw.yaml`; deshalb muss es ihn geben, auch wenn er noch leer ist. Diese Datei haelt ihn in git.
